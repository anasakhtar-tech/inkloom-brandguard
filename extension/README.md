# Inkloom BrandGuard - Chrome Extension (Manifest V3)
### Round 3 Final Improvement: In-Situ Real-Time Brand Governance Overlay

This extension injects the sub-15ms deterministic Inkloom BrandGuard governance engine directly into your active browser authoring workflows (Google Docs, Notion, WordPress, LinkedIn, Medium, Web CMS).

---

## 🚀 Quick Installation for Judges (Chrome / Brave / Edge / Chromium)

1. Open your browser and navigate to:
   `chrome://extensions/` (or `edge://extensions/`)
2. Enable **Developer mode** toggle in the top-right corner.
3. Click the **"Load unpacked"** button in the top-left.
4. Select this directory:
   `C:\Users\Acer\Desktop\Inkloom Hackathon Project\extension`
5. **Done!** The Inkloom BrandGuard shield icon will appear in your browser extension bar, and the ambient floating governance widget will activate automatically across web editors.

## 🎯 Key Architectural Capabilities
- **Manifest V3 Architecture:** Built on modern declarative service workers, ensuring zero background battery drain or memory leaks.
- **In-Situ Ambient Widget:** A floating pill at the bottom-right of your screen showing real-time governance health score (0-100).
- **Sub-15ms Local DOM Scanner:** Evaluates input fields, contenteditable regions, and textareas without transmitting text to external servers, preserving strict data sovereignty.
- **Cross-Platform Compatibility:** Runs seamlessly across Windows, macOS, Linux, and Chromium-based browsers, alongside our in-app Live DOM Sandbox Simulator.
